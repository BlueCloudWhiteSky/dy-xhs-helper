## 产品用途

养号助手适用于需要管理重复浏览任务、按关键词筛选内容，以及统一配置多台 Android 设备的使用场景。

- **个人使用**：在手机上分别保存各平台配置，安排运行时间，查看执行状态。
- **内容浏览与筛选**：按关键词和首页、搜索等场景浏览内容，减少重复操作。
- **团队管理**：在企业在线模式下集中配置规则、绑定设备、安排任务并查看操作记录。

使用前应确认账号和设备授权，以及平台是否允许拟进行的操作；具体要求见[免责声明](#免责声明)。

## 功能亮点

- **三平台入口**：在同一助手中选择小红书、抖音或微信视频号，每个平台分别保存规则。
- **关键词筛选**：按关键词匹配内容，支持对应平台的首页或推荐场景、搜索场景。
- **互动按需设置**：分别设置点赞、评论等互动概率，`0` 表示关闭；收藏能力因平台而异。
- **按时间运行**：配置运行日和时间段，在允许的时段执行任务。
- **状态与记录可查**：查看运行状态、日志与操作记录，核对任务执行情况。
- **支持企业管理**：通过 Web 管理后台管理设备、规则和授权，具体能力取决于开通方式。

养号助手的 Android 客户端以 **AutoJs6** 作为项目运行与开发基准，使用 JavaScript 脚本、无障碍服务和 UI 布局组织自动化任务。AutoJs6 也常写作 **Auto.js 6** 或 **autojs6**；相关技术主题包括 **Auto.js**、**AutoJS**、**autojs** 和 **Android automation**。

- **APK 用户**：安装已打包的 Android 应用，按本页教程设置权限、规则和授权，无需自行搭建脚本开发环境。

- **运行方式**：通过 Android 无障碍服务执行辅助操作，视频号另需系统截图授权；企业在线模式可结合 Web 后台管理设备与任务。

### 2 安装助手

打开下载的 APK，按 Android 系统提示安装。若提示未允许安装此来源的应用，仅为本次使用的浏览器或文件管理器授权；安装完成后可关闭该项权限。

覆盖升级应使用同包名、同签名的安装包。若出现签名冲突，请先联系支持，避免直接卸载造成本机配置和记录丢失。

### 3 准备目标应用

手动打开需要使用的小红书、抖音或微信，登录本人或获准使用的账号，确认可以正常浏览。登录、实名认证、验证码和账号异常提示应由用户按平台要求处理。

返回助手选择平台，查看“应用版本检测”；检测不通过时，按提示确认适配版本。

### 4 开启运行权限

1. 在助手首页开启“无障碍功能”。
2. 进入系统设置，找到养号助手并启用无障碍服务，再返回助手。
3. 开始任务时，按提示允许悬浮窗或“显示在其他应用上层”，用于运行控制与停止操作。
4. 运行期间保持设备解锁、竖屏和网络可用，避免手动切换页面或同时运行其他自动化工具。

不同品牌手机的设置入口可能不同。若系统限制后台运行，可在该应用的电池与后台管理中按需设置，并先做短时验证。

### 5 视频号额外设置

使用视频号前，在助手首页的“视频号截图权限”中点击“获取权限”，在 Android 系统弹窗中选择**共享整个屏幕**，保持竖屏，等待助手显示已获取。

截图授权属于当前系统会话。应用退出、停止共享或授权失效后，可能需要重新获取。若运行中因截图失效暂停操作，可通过首页权限入口重新授权后继续；正常运行期间无需重复申请。

## 使用教程

### 本机配置

免费单机试用和独立卡密授权使用手机上的配置：

1. **选择平台**：在首页选择小红书、抖音或视频号，确认权限和版本检查通过。
2. **填写规则**：点击“修改本机运行配置”，按需要填写以下内容。
3. **保存并开始**：保存后返回首页，点击“联网核验并开始试用”或“联网核验并开始运行”。
4. **查看与停止**：查看运行状态、日志和操作记录；结束时点击“停止运行”并确认，等待任务停止。

| 配置项 | 填写说明 |
| --- | --- |
| 筛选关键词 | 必填，多个词用中文或英文逗号分隔，例如 `摄影,构图` |
| 搜索模式 | 需要从搜索结果浏览时开启，并填写搜索词；关闭时使用对应首页或推荐场景 |
| 停留时间 | 小红书、抖音可设最短和最长秒数，范围为 `3` 至 `600`；最短不得大于最长；视频号无此本机设置 |
| 互动概率 | 点赞、评论范围为 `0` 至 `100`，`0` 为关闭；小红书、视频号另有收藏概率 |
| 评论文案 | 每行一条；开启评论前必须填写，并检查是否适合实际使用场景 |
| 运行时段 | 使用 24 小时制，例如 `09:00` 至 `09:15`；开始与结束相同表示全天 |
| 运行日 | 周一为 `1`，周日为 `7`，多个日期用逗号分隔；至少选择一天 |

运行时间按北京时间解释。互动概率不代表固定次数，也不保证实际执行结果。

首次可先关闭搜索模式，将互动概率全部设为 `0`，设置一个包含当前时间的短时段，确认浏览、页面识别和停止操作正常后再按需调整。修改配置后，应停止并重新开始任务，使新规则生效。

### 三平台操作要点

**小红书**：选择首页或搜索场景，配置关键词和停留时间，分别设置点赞、评论、收藏概率。若停留在评论弹窗或异常页面，先停止任务，手动回到正常的作品列表后重试。

**抖音**：选择首页浏览或搜索视频，配置关键词、停留时间、点赞和评论概率。当前本机配置不提供抖音收藏概率。出现验证码或账号风险提示时，应停止并由用户处理。

**微信视频号**：确认微信可正常打开且截图权限已获取，再选择推荐页或搜索视频。视频号的“推荐”和“收藏”是不同功能；缺少明确收藏入口或操作效果无法确认时，可能跳过或显示待确认。

### 企业后台配置

1. 在助手“我的”中输入企业码或对应在线卡密，点击“注册并激活”。
2. 企业码登记后，等待管理员审核；在线卡密按对应授权规则开通。
3. 管理员在 Web 管理后台配置平台规则、运行日和时间段，并绑定到设备。
4. 确认设备已审核、授权有效且未停用，在手机选择已绑定的平台开始，或由有权限的管理员从后台启动。

后台地址与账号由交付人员提供。运行中的任务使用启动时的规则快照，修改后的规则在下一次启动时读取。
